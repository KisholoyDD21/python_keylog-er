# Terminal Input Demo

A small Python example for handling a line of input entered directly into the
terminal. It reports the number of characters entered and does not save or
display the input content.

This project does **not** monitor keystrokes in other applications or write
input to a log file.

## Requirements

- Python 3.10 or later

No third-party packages are required.

## Run

```powershell
py keylogger.py
```

Type a line when prompted. The program prints its character count and exits.
